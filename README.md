# DK Concept Hair

Site oficial da DK Concept Hair, preparado em Next.js para GitHub e Vercel.

## Executar no computador

1. Instale o Node.js 22 ou superior.
2. Abra a pasta do projeto no terminal.
3. Execute:

```bash
npm install
npm run dev
```

4. Acesse `http://localhost:3000`.

## Publicar na Vercel

1. Crie um repositório no GitHub e envie todos os arquivos desta pasta.
2. Na Vercel, clique em **Add New → Project**.
3. Importe o repositório do GitHub.
4. A Vercel reconhecerá o projeto como **Next.js**.
5. Clique em **Deploy**.

Não é necessário configurar banco de dados nem variáveis de ambiente.

## Comandos

- `npm run dev`: abre o site localmente.
- `npm run build`: verifica e prepara a versão de produção.
- `npm start`: inicia a versão de produção após o build.
